# offside_norge

Bilder for Instagram-kontoen @offside_norge, hentet av Buffer via raw.githubusercontent.com.

- `lansering/` – de første postene (19.11.2026)
- `ko/` – tidløse poster i Buffer-køen (kl. 11.30)
- `nyheter/ÅÅÅÅ-MM-DD/` – daglige aktuelle poster (kl. 19.30, etter godkjenning)
- `verktoy/` – generator (`lag_poster.py`), fonter (Poppins, OFL) og profilbilde

Stilguide: claude.ai-prosjektet «Social media bot», `claude/offside-norge-stilguide.md`.
